# Phase 3: Validate (`fleet-dispatch.ts` - Pre-flight)

The **Validate** phase is a lightweight but extremely critical programmatic sanity check. It runs synchronously inside `fleet-dispatch.ts` *before* any downstream parallel coding agents are spawned.

## Purpose

Large Language Models, even when instructed not to, can hallucinate or fail to strictly follow rules. If Phase 2 (Plan) failed to obey the "Coupling Analysis" rule and assigned the same file (e.g., `src/api.ts`) to two separate tasks in `issue_tasks.json`, spawning agents for those tasks would guarantee a git merge conflict later.

This phase prevents wasted compute and merge nightmares by validating the **File Ownership Matrix**.

## Code Execution Path

```typescript
// scripts/fleet-dispatch.ts (Snippet)

const analysis = await Bun.file(tasksPath).json() as IssueAnalysis;

// Pre-dispatch ownership validation
function validateOwnership(analysis: IssueAnalysis): void {
  const claimed = new Map<string, string>();
  for (const task of analysis.tasks) {
    const allFiles = [...task.files, ...task.new_files, ...(task.test_files ?? [])];
    for (const file of allFiles) {
      const existing = claimed.get(file);
      if (existing) {
        throw new Error(
          `Ownership conflict: "${file}" claimed by both "${existing}" and "${task.id}". These tasks must be merged.`
        );
      }
      claimed.set(file, task.id);
    }
  }
}

validateOwnership(analysis);
console.log(`✅ Ownership validated: ${analysis.tasks.length} tasks, no conflicts.`);
```

## Inputs
* The `.fleet/YYYY_MM_DD/issue_tasks.json` file generated by Phase 2.

## Outputs
* **Success Path:** If the `claimed` map never encounters a duplicate key, the script logs a success message and proceeds to Phase 4 (Dispatch).
* **Failure Path:** If a duplicate file is detected, the script throws a synchronous `Error`. This crashes the process, stopping the GitHub Action pipeline. A human developer must then intervene, review the JSON, and manually merge the conflicting tasks into a single task before re-running the script.

## Context Sent to Jules
In this phase, Jules is **not invoked**. This is a purely deterministic script execution.
